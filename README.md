# IIRCo NDT — Android WebView

پروژهٔ مستقل از Kivy/Buildozer. فایل HTML و لوگو در خود برنامه قرار دارند.
مجوز اینترنت درخواست نمی‌شود. فرمول‌ها و هشدارهای HTML تغییر نکرده‌اند.
عکس پس‌زمینهٔ جدید هنوز اضافه نشده است.

## ساخت با گوشی و GitHub
1. یک مخزن جدید بسازید؛ پروژهٔ قدیمی را تغییر ندهید.
2. ZIP را استخراج کنید و محتویاتش را در ریشهٔ مخزن آپلود کنید.
   فایل settings.gradle و پوشه app باید در ریشه باشند.
3. پوشه مخفی .github را هم آپلود کنید. اگر فایل‌منیجر نشانش نمی‌دهد،
   در GitHub با Add file > Create new file فایل زیر را بسازید:
   .github/workflows/build-apk.yml
   و متن فایل YML ارائه‌شده را داخلش بگذارید.
4. در Actions، گردش کار Build Android APK را انتخاب کنید.
   با Run workflow اجرا کنید یا منتظر اجرای ناشی از push بمانید.
5. پس از سبزشدن اجرا، پایین صفحه در Artifacts، IIRCo-NDT-APK را بگیرید.
6. ZIP خروجی را استخراج و IIRCo-NDT-debug.apk را نصب کنید.
   در صورت درخواست اندروید، نصب از منبع مورد اعتماد را مجاز کنید.

## نکات
- این ZIP پروژه است، نه APK ساخته‌شده.
- ساخت و اجرا در محیط تهیهٔ پروژه انجام نشده؛ Java/Android SDK موجود نبود.
- CI نسخه debug با امضای آزمایشی می‌سازد؛ نسخه انتشار فروشگاهی نیست.
- کلید debug در اجراهای مختلف ممکن است تغییر کند. اگر نصب نسخه جدید
  خطای ناسازگاری امضا داد، نسخه آزمایشی قبلی را حذف و دوباره نصب کنید.
- برای نسخه انتشار، باید یک کلید امضای پایدار جداگانه تنظیم شود.
- برای ساخت محلی: JDK 17، Android SDK 35 و Gradle 8.9؛ دستور:
  gradle :app:assembleDebug
- گرادل توسط workflow نصب می‌شود؛ این پروژه فایل gradlew ندارد.
- این برنامه از Android System WebView گوشی استفاده می‌کند؛ کتابخانه بومی
  Kivy ندارد. اجرای واقعی روی گوشی همچنان باید آزمایش شود.
- محاسبات پرتویی برآورد هستند، نه تأیید ایمنی یا مجوز کار.
